# 🚀 EchoMateLite

EchoMateLite is a lightweight social media web application built using Flask, MySQL, and AWS. It allows users to create accounts, manage profiles, create posts, interact with other users, and explore a responsive social media experience.

## ✨ Features

- User Registration & Login
- Secure Password Hashing
- Profile Management
- Upload Profile Picture
- Edit Bio
- Create, Edit & Delete Posts
- Feed Page
- Search Users
- Follow / Followers
- Notifications
- Responsive Mobile UI

## 🛠️ Tech Stack

- Python (Flask)
- MySQL
- HTML5
- CSS3
- Bootstrap 5
- AWS EC2
- Gunicorn
- Nginx
- Git & GitHub

## ☁️ Deployment

The application is deployed on AWS EC2 using Gunicorn and Nginx.
